READ THIS AS A DEMONSTRATION

Clear evidence. Visible limits.

This website uses the anonymized values in Committee prep notes_template.docx. It demonstrates how a committee report can be presented online. It is not a validated compensation analysis or an approval recommendation.

What the charts use

Broad Incentive counts for 2028–2030 and the three 2030 Core Incentive group rows. No new observations or simulated records were added.

Coverage = recipients ÷ eligible × 100. Core rate = (Tier 1 + Tier 2) ÷ eligible × 100. Year-over-year count changes use 2029 as the baseline.

What stays out

Individual employee details, personnel comments, demographic breakdowns, placeholder spend, malformed counts and unverified percentage labels are excluded.

The template’s years are retained as supplied. They are scenario labels, not a claim about the current reporting cycle.

Why a longer history is not shown

The template changes from high grants in earlier years to Tier 1 and Tier 2 in 2030. It also contains repeated placeholder percentages, malformed values such as “2,30,” and mixed date references. These are not silently corrected or treated as a consistent time series.

Recipient count, coverage and spend answer different questions. Spend is masked in the document, so this demo makes no statement about budget growth, award size or return on investment.

How to use this web report

Switch between count and rate to test the headline. Select a year or group for the numerator and denominator. The explorer filters and exports the same six chart rows. “Print summary” produces the narrative and its current chart selections.

For a production report, confirm the source data and audience permissions before replacing this template. The browser receives the displayed dataset; hiding a row on screen does not restrict access to it.
